# PostagleSQL Study
PostgreSQLとPython(psycopg2)を用いた学習リポジトリ

LIT_HUBに学んだ際の気づきをのせています

## 主な学習内容
- CREATE TABLE
- INSERT
- SELECT
- WHERE
- ORDER BY
- GROUP BY
- HAVING
- JOIN
- UPDATE
- DELETE
- Subquery
- pythonからpostagleSQLを操作する方法

## 学習内容（できるようになったこと）
- テーブルの作成（CREATE TABLE）とデータの追加（INSERT）ができる
- SELECTを使って必要なデータを抽出できる
- WHEREを使った条件指定によるデータ取得ができる
- ORDER BYでデータの並び替えができる
- GROUP BYとHAVINGを使った集計・絞り込みができる
- JOINを使った複数テーブルの結合ができる
- UPDATE・DELETEによるデータの更新・削除ができる
- サブクエリを使った複雑なクエリの作成ができる
- Python（psycopg2）を使ってPostgreSQLを操作できる
- PythonからSQLを実行し、取得結果を扱うことができる
## 環境

- PostgreSQL 14
- Python 3.14
- psycopg2-binary

- python基礎→postgreSQL（ココ）→Pysparkへのステップアップ
- 実務を意識したデータ操作の習得
- SQLによるデータ抽出・集計の理解
